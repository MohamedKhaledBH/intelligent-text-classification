# Results

Everything here is traceable to the **original notebook run**; nothing was regenerated by the refactor
(no dataset, GPU or PyTorch was available when the repository was prepared).

## Naming convention
`{task}__{artifact}[__{model}][__{split}][__src-cell<N>].{csv|png}`

* `task`: `english_emotion`, `french_emotion`, `personality`, `eda`, `llm`
* `split`: `val` or `test` (omitted for EDA of the whole dataset)
* `__src-cell<N>`: the file was **re-exported from the recorded output of code cell N of the original notebook**
  (`archive/original_master_notebook.ipynb`, git-ignored). Files written by the refactored notebooks have no `src-cell` suffix,
  so they never overwrite these.

## What is a "recorded" result?
A value printed in the original notebook's cell output. It shows that the cell ran, but the refactor did **not** re-verify it:
the notebook has execution-order dependencies and some outputs were produced by older versions of the code (see REFACTORING_REPORT.md).
Tables printed as HTML data-frames keep pandas' 6-decimal display precision.
